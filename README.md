# claude-code-desktop
基于 Claude Code 的底层源代码构建，它支持访问各种 API，包括主要海外供应商、本地 Ollama 开源模型以及各种国内以代码为中心的大型模型。
对比claude code优势：
1.内置20多个服务提供商，复制apikey即可对话，一键支持glm，kimi，deepseek，minmax，各种token plan，国外御三家，支持本地模型调用，支持自定义模型调用。
2.内置搜索服务提供商，解决websearch非claude用户无法使用该工具问题。
3.支持软件内并行多会话（claude cli不支持）
4.内置浏览器，编辑器，shell终端，代码变更，会话内可按需打开查看执行 
5.命令，记忆，任务，技能，智能体，插件，mcp均可视化管理。
6.20多种命令，技能，子代理不同的渲染方式，显示更直观..

Instruction: Built based on the underlying source code of Claude Code.
Advantages over Claude Code:
Pre-integrated with more than 20 service providers. Simply copy the API key to start conversations. One-click support for GLM, Kimi, DeepSeek, Minimax, various token plans, the three major overseas providers, local model invocation, and custom model invocation.
Built-in search service providers, solving the problem that non-Claude users cannot use the web search tool.
Supports parallel multi-sessions within the software (not supported by Claude CLI).
Built-in browser, editor, shell terminal, and code modification features. All can be opened, viewed, and executed on demand within a session.
Visual management for commands, memory, tasks, skills, agents, plugins, and MCP.
Over 20 different rendering methods for commands, skills, and sub-agents, delivering a more intuitive display.
