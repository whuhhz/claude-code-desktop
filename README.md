# claude-code-desktop
built on the underlying source code of Claude Code, adopting a direct source code invocation approach and eliminating reliance on the CLI middleware. It supports access to a full range of APIs, including major overseas providers, local Ollama open-source models, and various domestic code-focused large models
基于 Claude Code 的底层源代码构建，采用直接源代码调用方式，无需依赖 CLI 中间件。它支持访问各种 API，包括主要海外供应商、本地 Ollama 开源模型以及各种国内以代码为中心的大型模型。
对比claude code优势：
1.内置20多个服务提供商，复制apikey即可对话，一键支持glm，kimi，deepseek，minmax，各种token plan，国外御三家，支持本地模型调用，支持自定义模型调用。
2.内置搜索服务提供商，解决websearch非claude用户无法使用该工具问题。
3.支持软件内并行多会话（claude cli不支持）
4.内置浏览器，编辑器，shell终端，代码变更，会话内可按需打开查看执行 
5.命令，记忆，任务，技能，智能体，插件，mcp均可视化管理。
6.20多种命令，技能，子代理不同的渲染方式，显示更直观..
